# bti Building Products Homepage — Final Design Reference

Open [index.html](index.html) with a local web server to review the final design draft for the WordPress rebuild. The preview uses remote images, fonts, GSAP 3.13.0, ScrollTrigger and Lenis 1.3.8. The native motion fallback keeps the preview usable if animation scripts fail.

## WordPress implementation

- Build a custom WordPress theme from scratch. Use this draft as the reference for responsive layouts, typography, spacing, imagery, navigation, gallery filters, hover states and motion.
- Recreate the front end with semantic HTML in WordPress templates, custom CSS and JavaScript. Enqueue version-pinned GSAP and ScrollTrigger for scroll-linked motion. Use Lenis for smooth scrolling where appropriate and respect reduced-motion preferences.
- Use WordPress core for editable content, navigation and the media library. Custom code can deliver the layout, gallery and animations without a page builder or animation plugin. Purchase a plugin only if a required production feature needs it.
- Connect quote and newsletter forms to their production handlers. The reference forms do not transmit data. Confirm complimentary service copy and the Brickworks association before publishing.

## Materials in real spaces

- Architectural screens and Outdoor surfaces retain their AOS-style entrance reveals and opposing horizontal scroll motion.
- Landscape possibilities, Exposed masonry and Interior feature walls have no AOS-style entrance, including in filtered views. Images, captions and arrows render without entrance fades or masks. Scroll-linked zigzag, image parallax and hover interactions remain. Exposed masonry still rises from below and reverses when scrolling back up.
- Verify both scroll directions, filters, lightbox, resizing and reduced motion in WordPress against the reference.
